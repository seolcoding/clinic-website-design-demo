# 가상 의원 디자인 데모

내과·치과·한의원 시안과 5개 디자인을 살펴보는 정적 데모입니다. 인물·공간·진료·장비·교육 이미지는 AI 합성입니다. 실제 의료기관·진료·예약·장비 보유·학회 참석을 나타내지 않습니다.

관리 화면과 실제 기관 원문 검토 자료는 이 공개 저장소에 포함되지 않습니다. 사이트는 `index.html` 한 파일이며 브라우저 안에서만 테마와 시나리오를 바꿉니다. `robots.txt`와 noindex는 검색 노출을 요청하지 않기 위한 신호이며 비공개 접근 제어가 아닙니다.

원본은 비공개 `clinic-gws-cloud` 개발 저장소의 `site/`에 있습니다. 새 버전은 로컬에서 `npm run build && node build-public.mjs`로 생성한 뒤 공개 파일만 검토해 게시합니다. 실제 병원 사이트로 전환하려면 기관 자료·의료광고·개인정보 검토와 별도 운영 배포가 필요합니다.
